## Instalación

Hola profe. Ejecute el siguiente comando para instalar las dependencias:

```bash
npm install

```

O de una manera más abreviada

```bash
npm i
```

> [!IMPORTANT]  
> Profesor, subí el `.env` porque hace falta para conectar la base de datos, decir que le token es válido solo por 30 días.
